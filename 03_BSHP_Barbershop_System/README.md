# Проект: Система онлайн-записи в сеть барбершопов (BSHP)

## 📌 Описание проекта
Учебный кейс по проектированию системы онлайн-записи. Основная цель — развитие бизнеса путем расширения клиентской базы за счет возможности самостоятельной записи, а также снижение трудозатрат сотрудников и уменьшение ручного труда за счет автоматического информирования клиентов по каналам связи.

## 🎯 Бизнес-цели системы
- Расширить клиентскую базу за счет удобной онлайн-записи 24/7.
- Снизить нагрузку на менеджеров (автоматические напоминания, исключение ручных звонков).
- Обеспечить контроль за санитарной обработкой помещений (согласно нормам Санэпиднадзора).

## 👥 Ключевые роли (Стейкхолдеры)
- **Клиент (посетитель):** выбирает услугу, мастера и время, получает напоминания.
- **Менеджер:** ведет расписание мастеров и услуг, принимает оплату, передает данные в бухгалтерию, контролирует санобработку.
- **Мастер:** просматривает свое расписание и отзывы.
- **Администратор:** управляет доступом к системе.
- **Бухгалтерия:** получает данные об оплатах.
- **Санэпиднадзор (Регулятор):** получает отчеты о санитарной обработке.
