# Портфолио системного и бизнес-аналитика

Привет! Меня зовут Алдын. Здесь собраны мои проекты по системному и бизнес-анализу. 
Я специализируюсь на выявлении требований, моделировании бизнес-процессов и проектировании ИТ-решений.

## 🛠 Мои навыки и инструменты
- **Нотации и моделирование:** BPMN, DFD, Swimlane, UML (State, Use Case), ERD.
- **Инструменты:** draw.io (diagrams.net), Microsoft Visio, Microsoft Excel, SQL, Swagger/OpenAPI.
- **Артефакты:** BRD/SRS (ТЗ), User Stories, Use Cases, Каталоги стейкхолдеров, Словари данных.

## 📂 Мои проекты

### 1. [Ozon PVZ Case](./01_Ozon_PVZ_Case/) — Реальный бизнес-кейс (ПВЗ)
Анализ проблем пункта выдачи заказов (очереди, потеря посылок) и проектирование локальной системы управления очередью и внутренним учетом посылок. Включает: As-Is/To-Be анализ, BPMN-диаграммы, User Stories и описание API.

### 2. [DELS Delivery System](./02_DELS_Delivery_System/) — Учебный кейс (Служба доставки)
Полный цикл проектирования ИТ-системы для стартапа в сфере доставки. Включает: Концепцию (Vision), диаграммы потоков данных (DFD), межфункциональные диаграммы (Swimlane) с артефактами, модели данных (ERD) и описание жизненного цикла заказа.

### 3. [BSHP Barbershop System](./03_BSHP_Barbershop_System/) — Учебный кейс (Барбершоп)
Проектирование системы онлайн-записи. Включает: анализ стейкхолдеров, луковичную диаграмму, модель данных (ERD), CRUD-матрицы и диаграммы состояний.
