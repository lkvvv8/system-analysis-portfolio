# Проект: Система онлайн-доставки заказов (DELS)

## 📌 Описание проекта
Учебный кейс по проектированию ИТ-системы для стартапа в сфере доставки. В рамках проекта был пройден полный цикл работы системного аналитика: от выявления бизнес-требований и построения модели As-Is до проектирования логической модели данных и описания архитектуры.

## 🎯 Бизнес-цели системы
- Обеспечить скорость распределения заказа (от ввода оператором до взятия курьером) в пределах 5 минут.
- Сократить время расчета и начисления оплаты курьерам до 1 рабочего дня за счет автоматической интеграции с 1С.

## 👥 Ключевые роли (Стейкхолдеры)
- **Курьер:** исполнитель доставки, использующий мобильное приложение.
- **Диспетчер:** контролирует курьеров, переназначает заказы при форс-мажорах.
- **Оператор ввода:** переводит заказы от партнеров в единый формат системы.
- **Администратор:** регистрирует персонал и настраивает права доступа.
- **Партнеры (магазины/рестораны):** поставщики заказов.
- **Бухгалтерия (1С):** внешняя система для расчетов.
